# LeetCode Solutions

[![LeetCode](https://img.shields.io/badge/LeetCode-solutions-FFA116?logo=leetcode&logoColor=white)](https://leetcode.com/)

My solutions to [LeetCode](https://leetcode.com/) problems, organized by language.
Each problem lives in its own folder with the solution and a bilingual (EN + PT-BR) write-up.

> Minhas soluções de problemas do [LeetCode](https://leetcode.com/), organizadas por
> linguagem. Cada problema fica em sua própria pasta, com a solução e uma explicação
> bilíngue (inglês + português).

## Structure / Estrutura

```
.
└── <language>/
    └── NNNN-problem-name/
        ├── solution.<ext>   # ready to submit on LeetCode
        └── README.md        # bilingual write-up (EN + PT-BR)
```

- `NNNN` is the LeetCode problem number, zero-padded to 4 digits.
- `<language>` groups solutions by programming language (e.g. `TypeScript/`).
